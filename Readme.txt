# Anna Malinowska – Personal Website

This repository contains the source code for my professional website, showcasing my education, experience, technical expertise, and portfolio of selected data analysis and bioinformatics projects.

🌐 **Live website:** https://anna-mal.github.io/

## About

The website provides an overview of my academic background, professional experience, technical expertise, and selected data analysis projects. It serves as a central hub where visitors can learn about my work in nutrition, microbiome research, bioinformatics, and clinical data analysis.

The website includes:

- 👩‍🎓 Education and academic background
- 💼 Professional experience
- 🛠 Technical skills and analytical expertise
- 📂 Portfolio of selected projects and case studies
- 📬 Contact information

## Technologies

The website was built using:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- GitHub Pages

## Running locally

Clone the repository:

```bash
git clone https://github.com/anna-mal/anna-mal.github.io.git
```

Then open `index.html` in your browser or serve the project using a local web server.
