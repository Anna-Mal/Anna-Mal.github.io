Omics 2022

Proteomics analysis

Project demonstrating analysis of proteomics datasets, including construction of a custom protein reference database based on microbiome composition data, downstream protein analysis, and biological interpretation of the results.

Bash scripting Linux R Studio

Project overview

Aim

Create a custom reference protein database derived from microbiome sequencing data and use it to analyze differences in protein composition and functional profiles between groups of interest.

Key insights
  • For functional gut microbiome analysis, shotgun metagenomic sequencing provides the most suitable basis for custom protein database construction due to its species-level taxonomic resolution.
  • Although custom protein databases can also be generated from 16S rRNA sequencing data, this approach requires multiple analytical decisions i.a. regarding taxonomic assignment of ASVs/OTUs and selection of representative species-level matches.
  • Construction of a study-specific protein database is important because using overly broad reference databases may increase false positive protein identifications.
  • In gut microbiome proteomics, the reference protein database should ideally be based on complementary analyses, such as sequencing data from the same samples, because microbial composition and predicted proteomes vary substantially across individuals, age groups, intestinal tract regions, and other biological or environmental conditions.
  • Appropriate normalization is a critical step in proteomics analysis, as it enables reliable comparison of protein abundances between experimental groups.
  • Hypothesis-driven enrichment analysis facilitates biologically interpretable conclusions by focusing on specific pathways, enzymes, or functional categories, while broader exploratory analyses remain valuable for novel hypothesis generation.
Data

16S rRNA amplicon sequencing and shotgun metagenomic sequencing data for custom reference protein database generation; Proteomics identification and quantification outputs generated with MaxQuant and FragPipe

Methods

Custom reference database generation using the Contigs Directed Gene Annotation (ConDiGA) workflow extended with proteomes of the most abundant microbial species, functional annotation using eggNOG-mapper, pairwise differential abundance analysis, functional enrichment analysis

Output

Bash scripts for custom database generation and proteomics preprocessing available on GitHub →

Analytical workflow

1

Reference database preparation

16S rRNA amplicon sequencing workflow

  • Taxonomic assignment of ASV sequences using BLAST and SILVA taxonomy
  • Selection of representative taxa based on sequence identity and abundance
  • Retrieval of reference proteomes from UniProt or NCBI using BUSCO-informed prioritization
  • Construction of a custom FASTA database covering the majority of microbial abundance
  • Protein clustering and redundancy reduction using CD-HIT
  • Iterative database refinement based on peptide identification performance
  • Detailed information can be checked here

Shotgun metagenomic sequencing workflow

  • Assembly of raw reads into contigs using MEGAHIT
  • Taxonomic annotation using Kraken 2
  • Gene coverage estimation with CoverM
  • Gene prediction using MetaGeneMark
  • Protein inference using the ConDiGA
  • Extension of the database with reference proteomes of confidently detected taxa
2

Database integration and annotation

  • Addition of human-derived and contaminant proteins
  • Merging of custom protein databases
  • Functional annotation using eggNOG-mapper
  • Removal of proteins lacking functional annotation
3

Proteomics data preprocessing

  • Import of MaxQuant and FragPipe outputs into R
  • Annotation harmonization and contaminant filtering
  • Low-prevalence protein filtering
  • Separation of microbial and human-derived proteins
  • Evaluation of normalization strategies for optimal sample separation
4

Exploratory analysis and visualization

  • Assessment of unique protein profiles across groups (Venn plots)
  • PCA and PCoA ordination analysis
  • Heatmap visualization of protein abundance patterns
5

Statistical and functional analysis

  • Differential abundance analysis using limma method implemented in tidyproteomics with volcano plot visualization
  • Functional enrichment analysis of significantly altered proteins

Tools & Packages

The analysis workflow consisted of two major components: custom reference proteome database construction performed on Linux-based high-performance computing (HPC) infrastructure (Snellius supercomputer) using Bash scripting, and downstream statistical analysis and visualization implemented in R Markdown.
